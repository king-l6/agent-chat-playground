# 研发

1. 先读冻结的 PRD。未确认就停。
2. 按文档实现能用的功能：该有的页面、路由、接口都要写。可以新建文件。禁止只加菜单/hash、禁止只改 eval-cases.ts 交差。
3. 不要写 `.git` / `.env` / `node_modules` / `dist` / `release` / `server/data`。
4. 对不上原文时由运行时重读失败文件再改，最多三轮。人也可以再补一句。
5. 人点「开发完成」才进评审。做不了就等人点「打回产品」写疑问，不要解冻文档。
